# STEAM-analysis

(Formerly `turbulon-analysis`, the name the dissertation uses.)

Analysis code for STEAM (Superposition of Turbulon and Eddy Atmospheric Model), Chapter 5 of *Weather and Climate Without Fluid Mechanics* (Thomas D. DeWitt, PhD dissertation, University of Utah, 2026).

Fly through STEAM-simulated clouds in the browser: [thomasddewitt.com/soar](https://thomasddewitt.com/soar).

The model code is in [STEAM](https://github.com/thomasdewitt/STEAM).
